# AuraMaker TikTok 運用メモ

初期認知用。フォロワー0からでもおすすめ枠を狙う前提の運用ルールと、AIに渡す共有コンテキスト。

サイト: https://auramaker.net  
一行定義: **自己申告じゃない。友達の票で決まる、他人目線のオーラ診断。**  
公式コピー: **自分では知らない、自分を知る。**

---

## やらないこと（ブレ防止）

- メール／プッシュなどうるさい外向き通知の訴求
- 生成AIでオーラを「判定」する話（票ベースが正解）
- Secret＝偉い、という設計・言い方
- 「精度98%」「科学的に確定」など偽の権威づけ
- シークレットの**具体条件ネタバレ**（言ってよいのは「投票10票以上で判定が開く」まで）
- 個人が特定できる他人の実名／顔出し素材（許可なし）

## 4ステップロードマップ

### ステップ1：型を2つに固定

最初から凝った編集はしない。スマホ画面＋CapCutのみ。

#### 型A：MBTIあるある × ギャップ（共感・拡散）

- 構成例: 「【悲報】ENFPの私が友達に印象投票させたら『盛り上げ番長（陽気なカオスオーラ）』出て草」
- 映像: アプリ操作の画面録画 ＋ オーラカードのスクショ ＋ 大文字テロップ

#### 型B：裏トリセツ解説（まとめ・興味付け）

- 構成例: 「友達10人以上から投票された奴しか出ない『シークレットオーラ』の条件がヤバい」
- ※条件の中身はぼかす。「10票以上で開く」「覚醒」「図鑑に Classified」程度まで
- 映像: オーラ球体 ＋ 「生息地」「弱点」テキスト ＋ 光る背景素材

### ステップ2：CapCut制作（9:16 / 10〜15秒）

1. 素材: 画面録画・結果カード画像・（あれば）画像シェア書き出し
2. 冒頭3秒フック: 中央に大テロップ  
   例: 「友達から見た自分の印象、知ってる？」
3. テンポ: 1〜1.5秒でカット切替
4. 音声: CapCutのテキスト読み上げで全テロップを自動読み上げ

### ステップ3：TikTok投稿設定

- BGM: トレンド音源をうっすら（音量 10〜20%）
- 検索対策: 概要欄＋アプリ内「テキスト追加」にキーワード  
  例: `MBTI 友達目線` `性格診断` `オーラ診断` `AuraMaker`
- 固定ハッシュタグ（5つ）:

```
#AuraMaker #MBTI #性格診断 #心理テスト #あるある
```

（補足で `#オーラ診断` `#友達目線` `#私のトリセツ` を足してもよい）

### ステップ4：1週間テスト運用

- 頻度: まず **1日1本**、**18:00〜21:00**
- CapCutでまとめて作り、下書き／端末保存しておく
- 投稿から24時間後に見る指標:
  - 再生数
  - 平均視聴時間（／完視聴に近いか）
- **再生 1,000 超えた型だけ量産**。伸びない型は捨てる

## 使える言い回し

- 友達目線 / 他人目線 / 観測 / 印象投票
- 自己認識とのギャップ / The gap is the point
- 通り名（例: 盛り上げ番長）＋正式オーラ名
- 生息地・弱点・副作用（生態パート）
- 観測信頼度・あとN票で覚醒（ゲーム進行としての票集め）

避ける:

- 「性格が確定した」「医療／適性検査」
- 「AIがあなたを診断」
- ネガ投票を煽る言い方（バカ・うざい等をそのまま煽らない）

```

プロダクト: 友達の票で決まる他人目線オーラ診断 https://auramaker.net
公式コピー: 自分では知らない、自分を知る。
制約:
- 尺 10〜15秒 / 9:16 / 型A（MBTI×ギャップ）か型B（裏トリセツ）
- 判定は友達票。AI判定・偽の科学表現は禁止
- Secret条件は「10票以上で判定が開く」まで。中身ネタバレ禁止
- Secret＝偉い、にしない
- CTAは auramaker.net（投票URL作成／友達に聞く）
- 固定タグ: #AuraMaker #MBTI #性格診断 #心理テスト #あるある
出力: フック3案 / テロップ全文（秒数つき） / 読み上げ原稿 / 概要欄 / カット表
今週の素材: （通り名・スクショ説明・型A or B）
```

- 「型Aで、ENFP×盛り上げ番長の15秒台本を3本」
