## 1. 盛り上げ番長（正式名：陽気なカオスオーラ）｜コモン

「予測不能なネオンが、場の温度を一瞬で上げる」

カオス系の絶対的エース。飲みの席やグループLINEに一人いるだけで空間が爆発します。

| 項目 | 内容 |
|------|------|
| 生息地 | 飲み会の中盤 / 深夜2時のタイムライン / グルチャが荒れた直後 |
| 発動条件 | テンション上昇 / 深夜0時を過ぎる / 会話が止まりかけた瞬間 |
| 弱点 | 真面目な会議 / 静かな図書館 / 盛り上げ役を休みたい日 |
| 副作用 | 周囲の予測能力が一時的に低下 / ノリが一段上がる |

本人は「今日静かにしとこ…」と思っていても、友達から

- 深夜テンション
- 草不可避
- 突然ボケる

が投票されて、満場一致で盛り上げ番長に確定するパターンが多発しています。

## 2. むっつりど変態（正式名：禁忌ネオンオーラ）｜レア

「好奇心が常にフルスロットル。禁断の質問を笑顔で投下する」

名前のインパクトが強すぎて、結果画面でいちばんスクショされるレアオーラ。

| 項目 | 内容 |
|------|------|
| 生息地 | 話が急に濃くなる雑談 / 趣味の深掘り / 夜になると別人になる瞬間 |
| 発動条件 | 好きな話題 / 禁断の質問が浮かんだ瞬間 |
| 弱点 | 真面目な自己紹介 / 上司がいる場 |
| 副作用 | 周囲の常識ゲージが一時的に溶ける |

「変態」「沼」「夜になると別人」「質問がえぐい」「趣味の解像度バグ」などのキーワードが揃うと解禁されやすいです。

本人は普通に喋っているつもりでも、友達目線では**「質問の角度がえぐい人」**として観測されている証拠です。
