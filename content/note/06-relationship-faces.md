「友達からは盛り上げ番長なのに、職場メンバーからは空気清浄機枠」

これ、矛盾じゃありません。**関係性が違えば、出る顔も違う**のが普通です。

AuraMaker（オーラメーカー）では、投票時に関係性（友達・恋人・職場・家族・その他）を付けられるので、集計すると「あなたにはNつの顔があります」という見え方になります。

## なぜ関係性でオーラが分かれるのか

人は相手によって、無意識にモードを切り替えます。

| 関係 | 出やすい顔の例 |
|------|----------------|
| 友達 | 盛り上げ番長 / 推し命銀河 / むっつりど変態 |
| 恋人 | 距離感近すぎ系 / メンヘラかまってちゃん / 小悪魔天使 |
| 職場 | 空気清浄機枠 / 頭回り最速マン / 説教聞かせマン |
| 家族 | 空気清浄機枠 / 主人公番長 / 夜更かし詩人 |

自己診断が1つでも、**観測者の席が変わればキャラが変わる**。  
それが「関係性ごとの顔」です。

## AuraMakerでの集め方

1. 投票URLを作る（https://auramaker.net）
2. 送る相手をバラす（親友だけに偏らせない）
3. 投票画面で関係性を選んでもらう
4. ダッシュボードで関係性ごとの顔を見る

ニックネームは任意。匿名のままでも、関係性だけ分かると十分おもしろいです。

## 顔が複数ある人の楽しみ方

- 「友達顔」と「職場顔」を並べてネタにする
- 恋人にだけ見せたい顔があるか確認する
- 関係性診断（ケミ）で二人の役割ストーリーを見る

パーセント相性より、「ボケとツッコミ型」「癒し合いユニット型」みたいな**役割の物語**の方が、話のネタになります。

- オーラが一つに決まらないのはバグではない
